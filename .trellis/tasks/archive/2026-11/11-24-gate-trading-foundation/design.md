# 父任务技术设计：Gate 交易基座

接口事实、口径与删除清单在计划文档第 3、5、8 节，本文件不重复。这里只记录跨子任务必须
保持一致的设计约定；各子任务的技术细节写在各自的 `design.md`。

## 分层与职责

```
trader/gate      Gate 适配层：合约元数据与张数换算、保护单、杠杆与保证金模式、账户权益
trader           交易路径：开仓加固、分批平仓、修改止损止盈、回撤监控
kernel           决策：金额计算与校验、决策契约、提示词
market/provider  行情：Gate 合约 K 线与 ticker 取数
api、web         图表 K 线、策略编辑器、助手行情工具
```

适配层只做"外部接口 ↔ 规范单位"的换算与校验，不含交易判断；金额计算与校验在 kernel；
交易判断只来自模型，系统只负责换算、校验与执行。

## 跨子任务设计约定

1. **下单数量的规范单位是合约张数**，以十进制字符串承载（如 `"3"`、`"0.6"`），直接作为下单
   接口的 `size`。标的币数量只用于展示，由张数乘 `quanto_multiplier` 得出。
2. **张数换算用精确十进制**，不用浮点除法截断（F3、F23）。取整只向下，取整到该合约的最小
   步长（带 `X-Gate-Size-Decimal: 1` 读取的 `order_size_min`）。
3. **外部数据解析失败即报错**。必然存在的字段解析失败、元数据自相矛盾（例如合约支持小数张
   但最小步长读成 0）都返回错误，不回落到猜测值。
4. **金额由代码计算**。模型只给出动作与必要的价格；开仓名义价值、张数、亏损上限由代码
   计算与校验，提示词契约不含金额字段。
5. **下单接口的成交核对以下单返回值为准**。已完结的委托在完结 10 分钟后不能按 ID 查询，
   开仓路径不依赖 `GetOrderStatus`（F25）。
6. **行情只来自 Gate**。其他交易所的 trader 分析行情用 Gate，下单取价用该交易所自己的价格，
   Gate 没有的品种不交易（D26）。

## 兼容、发布与回滚

- 不做兼容分支：旧语义随所属子任务一次性删除，失效的代码、测试与文档口径同步删除。
- 合入顺序受安全性不变量约束：恢复开仓能力的子任务（7 `account-equity`）排在开仓路径
  加固（4 `open-position-safety`）之后。
- 回滚点是一个子任务的提交边界：子任务在自己的 worktree 通过门禁后才合入父分支，失败时
  按提交边界手动恢复文件，不使用 git 回滚命令。
